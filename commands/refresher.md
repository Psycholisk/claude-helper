# Session Refresher

Review the entire conversation history of this session and produce a concise refresher with the following structure:

## 1. Session Digest
Provide a **very brief** (3-5 bullet points max) summary of everything discussed or worked on in this session. Each bullet should be one short sentence.

## 2. Last Thing We Were Working On
Describe in detail:
- **What** was the last task or topic we were actively working on
- **What we did** — the specific actions taken, changes made, or decisions reached
- **Current state** — where things stand right now (e.g., code was written, PR was created, investigation completed, etc.)

## 3. Pending Input / Waiting On User
Clearly state whether the session is currently **waiting for any input, feedback, or decision from the user**. If yes, specify exactly what is needed. If no, say so explicitly.

---

**Formatting rules:**
- Keep it short and scannable — no walls of text
- Use bullet points and bold text for emphasis
- Do not rehash full code snippets — just reference file names and what changed
- Write in plain, direct language
